# 🗣️ Phonetic Dictionary Web Crawler

A Python web crawler that automatically collects **words, grammatical categories, and phonetic transcriptions** from the Phonetic Dictionary on the [Portal da Língua Portuguesa](https://www.portaldalinguaportuguesa.org/).

The project sends HTTP requests to the portal, locates the results table, extracts the records, and organizes the data into CSV files separated by region.

---

## 📌 About the project

The crawler was built to automate the collection of phonetic data available on the portal.

For each selected region, the program:

1. Accesses the Phonetic Dictionary pages;
2. Iterates through the letters of the alphabet;
3. Automatically paginates using the `start` parameter;
4. Locates the `rollovertable` table;
5. Extracts the data contained in the HTML cells;
6. Organizes the records into:
   - Word;
   - Grammatical Category;
   - Phonetics;
7. Generates a CSV file for each region.

# 🚀 Installation

## 1. Clone the repository

```powershell
git clone https://github.com/steinbukken7321/phonetic-dictionary-crawler.git
```

Enter the folder:

```powershell
cd phonetic-dictionary-crawler
```

---

## 2. Create the virtual environment

On Windows:

```powershell
py -m venv .venv
```

---

## 3. Activate the virtual environment

In PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

After activation, the terminal should look similar to:

```text
(.venv) PS C:\...\phonetic-dictionary-crawler>
```

---

## 4. Install dependencies

With the virtual environment activated:

```powershell
python -m pip install --upgrade pip
```

Then:

```powershell
python -m pip install -r requirements.txt
```

---

## 5. Verify the installation

Run:

```powershell
python -c "import requests, pandas, inquirer; print('All dependencies installed successfully!')"
```

If you see:

```text
All dependencies installed successfully!
```

the environment is properly configured.

# 🔎 How the collection works

For each selected region, the crawler automatically goes through the letters:

```text
a → b → c → ... → z
```

For each letter, the portal paginates results using the parameter:

```text
start
```

Example:

```text
start=0
start=20
start=40
start=60
...
```

Each page usually contains up to 20 records.

When a page has fewer than 20 records, the crawler considers that letter finished.

---

# 📊 Collected data

Each record has three main fields:

| Field | Description |
|---|---|
| `Word` | Word found in the dictionary |
| `Grammatical Category` | Grammatical classification of the word |
| `Phonetics` | Corresponding phonetic transcription |

Example:

```text
Word                 Grammatical Category      Phonetics

a                    article                   a
a                    preposition               a
á-bê-cê              masculine noun            ˌa.bˌe.sˈe
a-pro·pó·si·to       masculine noun            a.pɾo.pˈɔ.zi.tʊ
```

# 💾 Generated files

Data is stored in the folder:

```text
data/
```

The file name uses the region code.

Examples:

```text
data/Dicionario_Fonetico_lda.csv
data/Dicionario_Fonetico_lbx.csv
data/Dicionario_Fonetico_rjx.csv
```

Files are saved using:

```python
encoding="utf-8-sig"
```

This correctly preserves:

- accents;
- special characters;
- International Phonetic Alphabet (IPA) symbols.

It also makes the files easier to open in Excel.

# ⚠️ Common issues

### PowerShell blocking the virtual environment

Run:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Then:

```powershell
.\.venv\Scripts\Activate.ps1
```

### Library not found

Check that the virtual environment is active and run:

```powershell
python -m pip install -r requirements.txt
```

### `requirements.txt` not found

Make sure the terminal is located at the project root:

```powershell
dir
```

You should see:

```text
main.py
requirements.txt
README.md
```

### CSV file doesn't appear

Check whether the crawler finished without errors:

```powershell
dir data
```

### Incorrect characters in the CSV

Files use:

```python
encoding="utf-8-sig"
```

to preserve special and phonetic characters correctly.
